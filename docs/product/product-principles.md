# Product Principles

- Mobile-first experience.
- Short and focused learning sessions.
- Practical explanations for software professionals.
- No advertisements in the initial release.
- No paid subscription in the initial release.
- No runtime AI functionality in the initial release.
- Educational content must be reviewed before publication.
- User progress must be reliable.
- Product-visible decisions require human approval.
- Prefer simple architecture until additional complexity is justified.
