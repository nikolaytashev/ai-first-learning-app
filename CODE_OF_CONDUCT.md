# Code of Conduct

## Expected behaviour

Project participation must be professional, constructive and focused on the
work. Contributors must respect differing experience levels, provide actionable
feedback, protect private information and avoid harassment, discrimination,
threats or personal attacks.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions
and other project spaces. It also applies when someone is representing the
project publicly.

## Enforcement

Report conduct concerns privately to the repository owner through the contact
method on the owner's GitHub profile. Do not publish sensitive reports as
issues. The owner may edit or remove content, limit participation or ban a
participant when necessary to protect the project and its contributors.

Reports will be reviewed as privately as practical. Deliberately false or
retaliatory reports are themselves violations of this policy.
