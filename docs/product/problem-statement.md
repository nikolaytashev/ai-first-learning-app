# Problem Statement

Software professionals need to learn AI and core software-engineering topics
while balancing full-time work and other responsibilities. Existing material is
often fragmented, too broad for short study sessions or disconnected from
practical engineering decisions.

The product should provide a structured mobile learning path made of short
lessons, checks for understanding and reliable progress tracking. The first
pathway focuses on AI Fundamentals for Software Engineers.

## Initial assumptions to validate

- The target users will prefer focused mobile sessions over long-form courses
  for recurring study.
- Explanations after quiz answers will be more useful than scores alone.
- Reminders and resume-learning support will improve continuity.
- Limited offline access to opened lessons will be sufficient for the first
  release.

These are product hypotheses, not proven facts. The Product Manager must connect
feature proposals to measurable validation criteria and must not present these
assumptions as user research.
