# Architecture Decision Records

Use one Markdown file per durable architecture decision. Name files
`NNNN-short-title.md` and include status, context, decision, consequences and
superseded records.

Allowed statuses are `Proposed`, `Accepted`, `Rejected`, `Deprecated` and
`Superseded`.

Agents may draft a `Proposed` record. Only the human owner may accept a record
that changes product scope, privacy, security boundaries, public APIs,
deployment authority or autonomous-agent authority.
